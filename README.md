# Roubian OS
Una edición minimalista de **Debian** diseñada para la velocidad y la eficiencia.

## 🚀 Filosofía
Roubian no es una distro pesada. Es una configuración optimizada basada en Debian, enfocada en el rendimiento mediante el uso del Kernel XanMod, Openbox y un conjunto de herramientas minimalistas.

## 🛠️ Stack Tecnológico
- **Base:** Debian Minimal
- **Kernel:** Linux XanMod (x64v3)
- **WM:** Openbox
- **Barra:** Polybar
- **Terminal:** Kitty
- **Gestor de red:** NetworkManager
- **Compositor:** Picom

## 📦 Instalación
Para instalar Roubian en una instalación limpia de Debian, ejecuta:

```bash
git clone [https://github.com/Roussel19/Roubian-OS](https://github.com/Roussel19/Roubian-OS)
cd Roubian-OS
chmod +x install.sh
sudo ./install.sh
